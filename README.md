# 마리박현숙 — 온라인 갤러리 · 포트폴리오

화가 마리박현숙의 개인 작품 포트폴리오입니다. 관리자가 그림을 등록하고 누구나 작품을 감상합니다. 작품명·작가·연도·설명을 저장하고 작품명/제작 연도로 검색할 수 있습니다. Python 3.12 이상을 사용하며 이미지 처리와 클라우드 연결 패키지는 `requirements.txt`에 정의되어 있습니다.

메인은 시리즈 제목 칸과 해당 작품 칸이 이어지는 격자입니다. 시리즈 제목을 누르면 해당 시리즈의 작품이 가로로 펼쳐집니다. 메인과 시리즈 화면 어느 곳에서든 작품을 누르면 바로 상세 보기가 열립니다. 상세 화면의 ‘작품 편집’에서 정보, 시리즈와 이미지를 수정할 수 있습니다. 이미지를 선택하지 않으면 기존 그림이 유지되고, 서버에서는 관리자 비밀번호가 필요합니다. 등록 시 시리즈 제목을 드롭다운에서 선택하면 같은 시리즈의 작품끼리 묶입니다. 새 시리즈는 ‘+ 새 시리즈’를 선택해 입력합니다. 기존 시리즈 이름은 관리자 창의 ‘시리즈 이름 수정’에서 시리즈를 선택하고 새 제목을 저장합니다. 해당 시리즈에 속한 작품 전체가 반영되며, 다른 시리즈와 같은 이름으로 합치는 변경은 허용하지 않습니다. 서버에서는 관리자 비밀번호가 필요합니다. 작품명·제작 연도·재료/기법·가격·크기·호수를 입력할 수 있으며 상세 보기에 기재된 정보만 표시합니다. 가격은 통화가 포함된 금액이나 ‘가격 문의’처럼 자유롭게 입력합니다. 미지정 작품은 Works로 묶이며, 기존 데이터는 서버 실행 시 보존하여 자동 마이그레이션합니다. 검색은 작품명·시리즈·제작 연도에 적용됩니다.

미리보기 생성 시 등록된 작품이 있으면 이미지를 포함합니다. 등록된 작품이 없을 때의 Series 01–03과 회색 프레임은 배치 확인용이며 실제 작품이 아닙니다.

가로·세로는 cm 단위로 각각 입력합니다. 1~100호의 등록된 F/P/M/S 규격표와 비교하며 가로·세로 방향에 상관없이 자동 표시합니다. 제조사 표기의 1mm 반올림 차이를 허용하고(각 변 최대 0.15cm), 맞는 규격이 없으면 ‘비규격’으로 표시합니다. 추정한 최근접 호수를 지정하지 않습니다.

전시 페이지의 ‘전시 등록’에서 전시명, 장소, 시작일과 종료일을 입력합니다. 예정·진행 중 전시는 최신 전시에 표시되고, 한국 시간 기준 종료일 다음 날 00:00부터 지난 전시로 분류됩니다. 페이지를 열어둔 경우에도 자정에 다시 분류하고, 잠든 탭은 다시 활성화될 때 갱신합니다. 등록된 날짜 자체를 변경하거나 기록을 삭제하지 않습니다. 미리보기의 전시 데이터도 브라우저 저장과 갤러리 백업에 포함됩니다.

## 실행

```sh
cd /workspace/travel
python3 -m pip install -r requirements.txt
python3 server.py
```

기본 포트는 3000이며 `PORT`로 변경합니다. 관리자 비밀번호는 첫 실행에 `.gallery/admin-password`에 자동 생성됩니다. 파일 내용은 관리자만 안전하게 확인하고 공유하거나 커밋하지 마세요. `GALLERY_ADMIN_PASSWORD` 환경 변수로 비밀번호를 지정할 수도 있습니다. 브라우저의 ‘관리자 · 작품 등록’에서 비밀번호와 작품 정보를 입력합니다.

## 목록 로딩과 이미지 캐시

첫 화면은 `/api/gallery` 한 요청으로 작품과 작가노트를 읽습니다. 공개 목록은 ETag로 재검증해 편집 직후 최신 정보를 보여주며, 관리자 메모와 오류 응답은 저장하지 않습니다. 서버가 새로 시작될 때 기존 DB 구조와 접근 권한을 한 번의 조회로 확인하고, 필요한 경우에만 마이그레이션합니다.

작품·전시 목록은 `/api/thumbnails/640/<파일명>` 또는 `1280`의 WebP 사본을 사용합니다. 기존 업로드도 첫 요청 때 생성하며, 원본 비율·회전·색상 프로필을 보존합니다. 상세 화면은 원본을 표시하고, 사본 요청이 실패하면 목록도 원본으로 전환합니다. 업로드마다 고유한 파일명이 생기므로 사본은 브라우저와 CDN에 오래 캐시할 수 있습니다. Vercel의 이미지 함수는 DB 초기화와 독립적으로 실행되며, 미리보기 HTML은 포함된 이미지를 그대로 사용합니다.

검증용 1800×1200 JPEG의 브라우저 비교에서는 첫 이미지가 1,939,072바이트에서 131,594바이트로 줄었습니다. 이는 테스트 파일의 전송량 비교이며, 운영 사이트의 응답 시간 측정치는 아닙니다.

그림과 SQLite 데이터베이스는 `.gallery/`에 보관됩니다. 프로세스 재시작 후에도 유지됩니다. `GALLERY_DATA_DIR`로 별도 영구 저장 경로를 지정할 수 있습니다. 백업할 때는 서버를 정지한 후 이 디렉터리 전체를 복사하세요.

## 검증

HTML 파일만 열어 디자인을 확인하려면 `python3 export_preview.py`를 실행하고 생성된 `gallery-preview.html`을 여세요. CSS와 JavaScript가 포함된 단일 파일입니다. 이 파일에서도 작품을 등록할 수 있습니다. 브라우저가 허용하면 IndexedDB에 저장되며, 사용할 수 없으면 localStorage 저장을 시도합니다. 두 저장소가 모두 차단된 미리보기 환경에서는 현재 화면의 메모리에만 유지됩니다. 관리자 등록 창의 저장 안내를 확인하세요. 관리자 창의 ‘작품 백업’은 이미지, 작품, 전시와 작가노트를 포함한 단일 HTML 파일을 내려받습니다. ‘백업 불러오기’에서 해당 HTML 또는 JSON 스냅샷을 가져올 수 있습니다. 같은 ID의 기존 작품과 같은 시리즈의 기존 노트는 유지해 중복과 덮어쓰기를 방지합니다. 호스트가 다운로드를 제한할 수 있으므로 파일이 실제로 저장되었는지 확인하세요. 브라우저 등록분은 클라우드 서버나 다른 기기에 자동 반영되지 않습니다. 서버 저장과 관리자 비밀번호 인증은 `python3 server.py`로 실행한 앱에서 이용합니다.

```sh
python3 -m unittest discover -s tests -v
node --test tests/test_rules.cjs
```

## 공개 운영 전

현재 개발용 첫 버전입니다. 공개 운영에는 HTTPS, 관리자 로그인 시도 제한, 이미지 디코딩 검증 및 재인코딩, 영구 스토리지와 백업이 필요합니다. 현재 이미지 검사는 파일 시그니처 검사이며 전체 디코딩 검사는 아닙니다. 판매·회원가입·작품 삭제 기능은 포함하지 않습니다.

## Contact 비공개 메모

방문객은 Contact에서 이름·답변받을 연락처(선택)와 메모를 남길 수 있습니다. 메모는 SQLite에 저장되며 공개 목록은 제공하지 않습니다. 관리자 메모함에서 비밀번호 인증 후 조회할 수 있고, 창을 닫으면 표시한 내용과 비밀번호를 지웁니다. 비밀번호와 메모는 갤러리 백업 HTML에 포함하지 않습니다. 파일 미리보기에서는 메모를 전송하지 않으며 접수되었다고 표시하지 않습니다. 실제 접수·조회는 실행 중인 Python 서버에서 이용하세요.

## 시리즈 작가노트

관리자 창의 ‘시리즈 작가노트 편집’에서 시리즈별 글을 입력합니다. 메인 시리즈 제목 칸과 시리즈 제목 아래에 일부 내용이 표시되며 아래쪽은 흐려집니다. 누르면 전문을 읽는 별도 화면이 열리고, 돌아가기를 누르면 이전 위치로 돌아옵니다. 빈 노트는 표시하지 않습니다. 공개된 글은 일반 텍스트로 표시하고 HTML을 실행하지 않습니다. 저장한 노트는 시리즈 이름 변경, 브라우저 저장 및 백업에 함께 반영됩니다. 실제 서버에서는 작가노트 저장에도 관리자 인증이 필요합니다.

## 공개 배포

카드 없는 배포 구성은 Vercel Hobby + Supabase Free입니다. 설정은 `vercel.json`, 연결 순서는 [DEPLOY.md](DEPLOY.md)를 참고하세요. 로컬 SQLite 모드도 유지됩니다. Supabase 서버 실행에는 `requirements.txt`의 psycopg가 필요합니다. 이미지 한 장의 업로드 제한은 3MB입니다.
